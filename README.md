# 约会记录 · Dating Record

本地优先的个人关系档案工具。三层模型：**人物（动态属性）/ 事件集（可嵌套）/ 事件**。

数据全部存在你自己的浏览器里（SQLite WASM + IndexedDB），**支持随时导出为单文件 JSON 备份**。

## 快速开始

```bash
pnpm install
pnpm dev        # 开发模式（默认 http://localhost:5173）
pnpm build      # 类型检查 + 生产构建（输出 dist/）
pnpm preview    # 预览构建产物
```

> 首次打开点击「载入示例数据看看效果」即可看到完整界面。

## 功能（v0.1 试水版）

| 模块 | 已实现 |
|---|---|
| 人物 | 创建、改名、标签、归档；**属性动态增减**（9 种控件类型 + 属性字典自建字段）；**属性模板**（新建时套用 / 详情页套用与另存）；统计（事件数 / 最近见面 / 总花费 / 平均评分） |
| 事件 | 创建/编辑/软删除/回收站；**六种时间模型**（时刻 / 区间 / 模糊 / 进行中 / 未知）；参与者、地点、评分、花费、心情、亲密度、标签、**Markdown 正文**（编辑时实时语法高亮；`[附件](file:id)` 与内嵌 HTML 的 `<a href="file:id">` / `<img src="file:id">` 都能打开文件库里的文件，`<a>` 指向图片时直接显示图片）；**聊天形式**（消息气泡 + 旁白，整段对话可全屏看）；多集合归属；**事件关联**（后续 / 起因 / 同日，双向可见） |
| 事件集 | 无限嵌套（闭包表）、移动（含环检测）、成员增删、上下移动排序、面包屑、子集合；**智能集合**（关键词/标签/类型/人物/评分/时间窗规则，成员实时求值）；**自定义图标**（单文字 / 双字母 / SVG / 图片，可选前后景色，上传或从图库选） |
| 时间线 | 按月分组、关键词搜索、多条件筛选（人物/集合/类型/评分/时间范围/标签） |
| 日历 | 月视图：过去灰 / 今天黄 / 将来白，格子上方日期、下方当天的事件集图标；点某天回时间线只看那天 |
| **背景音乐 / 歌单** | 后台播放本地音频（离开面板不断）；**歌单就是文件库里的 `.drpl` 文件**——新建 / 导入 / 可视化增删排序 / 改名改描述 / 删除，编辑自动写回；文件库可按「歌单」类型筛选、点开预览直接播放；未选歌单时退回本机临时队列 |
| **备份** | **导出 `.drp.zip`（库数据 + 附件原文件）**、**合并导入（按 hlc 比较，本地更新不被覆盖）**、**替换导入（自动先备份）** |
| **坚果云备份** | **增量同步**：库切成 64KB 内容寻址分片，只传云端没有的那几片（改一句话通常只传 1 片）；三方比对（本机没改只下载 / 两边都改先按 hlc 合并再上传）；远端留 10 份历史快照；密钥与凭据不进备份 |
| **AI 模型** | **按别名管理模型**：别名 + 服务商（硅基流动 / OpenAI 兼容 / Ollama / 自定义）+ 模型名 + 温度/长度；读服务商模型列表、测试连通；密钥按服务商存本机，不进备份 |
| **AI 对话** | 设置 → AI → AI 对话。**助手**支持多轮思考 + 连续调用工具（查数据 / 建人物 / 记事件 / 整理聊天记录），工具调用全程可见；**每轮第一次写库前自动拍整库快照**，不满意一键回退。可**上传文件**（本地文件 / 文件库）：文本读内容、图片走视觉，附件只随该条消息发送、不入库 |
| **命令行 CLI** | 同一套能力的命令行入口（`npm run build:cli` 后 `node dist-cli/cli.cjs …`），输出 JSON、可脚本化；写操作同样自动快照。详见 [`docs/cli.md`](docs/cli.md) |
| **系统快照** | 整库落盘备份（独立于库文件存放），AI / CLI 动手前自动拍；列表、恢复（恢复前再自动留底）、删除，上限 20 份 / 64MB |
| 隐私与安全 | **应用锁**（口令 + 空闲自动锁）、**本地库加密**（口令 + 恢复码，CTR 密文落 IndexedDB）、**隐私模式**（人物 / 事件集 / 事件 / 文件可逐一标记，开启后全局隐藏） |
| **分享** | **一个「开始分享」按钮，四步向导**：多选事件集（可展开挑具体事件，事件集与事件都能点开看详情）→ 选人物（事件涉及的人必带，可加选其他人）→ 分享程度 → 预览（点事件集看包内详情、点人物看裁剪后的资料、点事件看正文）；任意一步可回退改选择，导出 `.drshare.zip`；导入前先预览，同名人物自动关联、可改，事件集可新建或并入已有 |
| **外观** | 设置 → 外观：8 个预设主题色 + 任意色值，5 种浅色底（暖白 / 米色 / 冷白 / 浅灰 / 雾粉），选完立即生效；颜色过浅会自动加深，保证白字对比度不低于 3:1；偏好只存本机（localStorage），不进备份 |
| 设置 | 二级目录 + 分组图标：备份与分享（数据备份 / 坚果云备份 / 分享） / **外观** / **AI**（点进去是二级目录：AI 对话 / 聊天提取 / 模型） / **隐私与安全** / **人物与属性** / 归档与回收 / 文件 / **数据与统计** / **功能体验**（边缘分割、未完成的记录），目录上直接显示锁与加密的状态 |
| 数据层 | ULID、HLC 混合逻辑时钟、软删除墓碑、oplog 操作日志、fractional index 排序 —— 为将来跨端同步埋好点 |

```

├── core/                 纯逻辑层（不依赖 React）
│   ├── db.ts             sql.js + IndexedDB 持久化、建表、迁移、事务、oplog
│   ├── types.ts          领域类型

│   ├── order.ts          fractional index 排序键
│   ├── io.ts             导入导出 + 行/对象映射

│   └── repo/             persons / events / collections 三个仓储
├── ui/                   React 界面
└── store.ts              写操作后的版本号广播（各组件自动重查）
```

## 数据备份说明

- 默认导出文件名：`dating-record-YYYYMMDDHHmm.drp.zip`
- 压缩包内容：`library.json`（结构化数据）+ `attachments/`（附件原文件）+ `manifest.json`（版本与附件清单）
  附件不再 base64 内联，体积比单个 JSON 小得多，方便传网盘/同步
- 导出只产出 `.drp.zip`，不再提供 JSON 下载
- 选择框只收 `.drp.zip`；旧的 `.drp.json` 备份可用 CLI 的 `io.importLibrary` 导入
- 导入合并逻辑：同 ID 时比较 `hlc`，本地更新则跳过（不会用旧备份覆盖新数据）；替换导入会先自动导出一份 zip 备份

## 坚果云增量备份

远端目录结构：

```
<远端目录>/
├── manifest.json          清单：这一版库由哪些分片按顺序拼成（每片的大小与内容哈希）
├── chunks/<hash>.bin      分片，内容寻址，永不改名复用
└── snapshots/s<ts>.json   历史快照（只保留最近 10 份）
```

每次同步只上传「云端清单里没有的哈希」：

| 场景 | 上行 | 下行 |
|---|---|---|
| 数据没变 | 0 | 0 |
| 改一条事件 | 1 个 64KB 分片 + manifest（几百字节） | 0 |
| 另一台设备改过、本机也改过 | 合并后的新分片 | 对端的分片 |

> **浏览器跨域**：坚果云的 WebDAV 不返回 CORS 头，从网页直连会被浏览器拦。
> 设置页里的「高级 → 服务地址」可以填一个转发到 `https://dav.jianguoyun.com/dav` 的反向代理。
> 密码要用坚果云的**应用密码**（账户信息 → 安全选项 → 添加应用密码），不是登录密码。

## AI 模型

位置：设置 → AI → 模型。模型配置是一行「别名 → 怎么调」：别名用于调用时选择（`便宜好用的` 比 `Qwen/Qwen2.5-7B-Instruct` 好记），
同一模型可起多个别名配不同温度。API 密钥按**服务商**存一份，多条别名共用。

- **服务商可自选**：硅基流动（地址固定、免填）/ OpenAI 兼容·第三方端点（DeepSeek、Moonshot、OpenRouter、自建网关都填这里，改根地址即可）/ 本地 Ollama（默认 `localhost:11434`，可改成远程）。「OpenAI 兼容」和「自定义」已合并——本质都是填一个 `/v1` 根地址
- **能力标注**：给每个模型勾选能处理的多模态（文本 / 图片 / 视频 / 音频 / 文件），不同功能按能力挑模型
- **能力能否自动识别**：标准 `/v1/models` 接口（硅基流动、OpenAI、DeepSeek、Moonshot 等）**只回模型 id、不回能力字段**，所以能力需手动勾选；若某服务商在该接口返回 `capabilities`（如 OpenRouter 风格的 `vision`/`speech`），代码会自动解析并预填
- 只依赖 `/v1/models` 与 `/v1/chat/completions`，所以硅基流动、DeepSeek、Moonshot、Ollama、自建网关都能用
- 密钥存 `meta` 的 `ai.key.<provider>`，不进备份、不进云端快照（与坚果云凭据同一套剔除规则）
- 模型配置本身进备份并随同步走 —— 换台机器不用重配

## 命令行（CLI）与 AI 工具调用

这个项目的每一项能力都同时在**三个入口**可用：网页 UI、命令行、AI 助手。
三者共用 `src/core/tools` 里的同一份工具注册表（一个能力只有一份实现），
所以新增功能时只要在注册表里声明一条 `ToolDef`，CLI 和 AI 自动就能用。

```bash
npm run build:cli                                  # 构建 dist-cli/cli.cjs
node dist-cli/cli.cjs tools                        # 看全部工具
node dist-cli/cli.cjs person.create --displayName 张三
node dist-cli/cli.cjs event.list --from 2024-01-01
node dist-cli/cli.cjs snapshot.restore --id snap_xxx   # 回退
```

- 操作的是普通 SQLite 文件（默认 `./dating-record.sqlite`，`--db` 可改），
  与网页版数据互通（CLI 用 `io.exportLibrary` / `io.importLibrary` 交换 JSON；网页用「数据备份」交换 `.drp.zip`）
- 写操作前自动拍整库快照，结果里带 `_snapshot` 字段，误操作可整笔退回
- 输出一律 JSON（stdout），方便 `| jq` 接管道
- 详细说明：[`docs/cli.md`](docs/cli.md)

## 已知限制（试水版）

- 单端单浏览器，暂无同步（数据模型已埋点，见 `dating-record-storage-sync.md`）
- 附件无批量拖拽上传，但文件库已支持上传 / 预览 / 改名 / 引用 / 隐私标记
- 隐私模式是**查看偏好**（localStorage），不是加密——真要挡住别人请配合应用锁
- 外观目前只有浅色底与主题色，深色模式尚未覆盖（不少组件仍写死白底，需要逐个改造）
- 统计图表、模糊时间解析为 v1 范围（智能集合已交付）
